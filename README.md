# Reinald Mendes — Soluções em gestão e tecnologia

Landing page / portfólio pessoal, em um único arquivo HTML (CSS e JS embutidos, sem dependências externas além das fontes do Google Fonts).

## Conteúdo
- Apresentação e área de contato (WhatsApp, LinkedIn, GitHub, Instagram)
- Portfólio com filtros: Trilhas da Infância, Maxx Confort, Reflorescer Artesanal Natural, Loja Joias Rose Monteiro, Gestão Esportiva (Jogos Escolares) e automações em Google Apps Script
- Tema claro/escuro automático (com alternância manual)
- Layout responsivo, do celular ao desktop

## Como publicar no GitHub Pages
1. Envie este repositório para o GitHub (mantendo o nome `index.html` na raiz).
2. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
3. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Editar conteúdo
Todo o site está em `index.html`. As seções de portfólio, textos e links estão organizadas por comentários HTML (`<!-- PORTFÓLIO -->`, `<!-- CONTATO -->` etc.) para facilitar futuras edições.
